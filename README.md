# 권리ON · 알바 권리 O/X 아케이드 퀴즈

부스 방문자와 학생·청소년·아르바이트 노동자가 쉽고 재미있게 노동법 핵심 권리를 확인할 수 있는 **16컬러 CRT 아케이드 스타일 O/X 퀴즈 웹앱**입니다.

## 주요 기능

- **즉각적인 O/X 퀴즈 & 법적 해설**: 1번 문제부터 바로 시작해 O/X 선택 즉시 정답 여부와 관련 법조항 해설을 확인합니다.
- **부스 & 모바일 QR 겸용 설계**:
  - **QR 스캔**: 하단 `QR` 버튼으로 현재 화면의 QR 코드를 띄워 방문자가 본인 스마트폰으로 바로 참여할 수 있습니다.
  - **원클릭 부스 리셋**: 하단 `BOOTH RESET` 및 결과 화면의 `다음 참가자 시작` 버튼으로 다음 방문자를 위해 즉시 초기화됩니다.
  - **키보드 단축키** (노트북/태블릿 키보드 부스용): `O` / `←` (맞다), `X` / `→` (아니다), `Enter` / `Space` (다음/재시작), `C` (CRT 주사선 ON/OFF), `M` (8비트 효과음 ON/OFF), `R` (리셋).

## 새로운 Q&A 문항 추가하기

[`src/data/questions.ts`](src/data/questions.ts) 파일의 `QUESTIONS` 배열에 새 문항을 추가하면 스테이지 수, 점수, 진행 보석(`StageGem`), 결과 리뷰가 자동으로 반영됩니다.

```ts
{
  id: 6,
  category: '주휴수당',
  question: '여기에 O/X 질문을 입력하세요.',
  answer: 'O', // 'O' 또는 'X'
  lawRef: '근로기준법 제00조',
  explanation: '정답 확인 직후 보여줄 1~2문장 해설을 입력하세요.',
}
```
